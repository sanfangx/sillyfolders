# SillyTavern Folders (角色与对话文件夹插件)

一个轻量直观的 **SillyTavern（酒馆）** 第三方扩展插件，为 **角色卡 / 群组**、**首页“最近的聊天”** 以及 **历史对话管理弹窗** 提供原生风格的文件夹分类管理。

## 功能特性

1. **角色卡与群组文件夹（右侧角色列表）**
   - 在角色列表顶部提供面包屑导航、返回上级、新建文件夹、批量整理与根目录显示切换。
   - 支持**多级子文件夹**与自定义颜色标记。
   - 多种移入方式：
     - 点击角色卡 / 群组卡片右上角文件夹图标，打开文件夹选择器（支持弹窗内一键新建并移入）。
     - 直接将角色卡 / 群组卡片**拖拽**到文件夹卡片或面包屑导航中。
     - 点击工具栏 **批量整理** 一次性勾选多张角色卡移入或移出文件夹。
     - 兼容酒馆原生列表视图、网格视图（Grid View）及原生批量编辑模式（Bulk Edit）。
   - 删除文件夹**绝不会删除角色卡或对话本身**，其中的内容会自动退回上级或根目录。

2. **对话文件夹（首页“最近的聊天”界面 & 历史对话管理）**
   - 直接在首页欢迎界面的 **最近的聊天（Recent Chats）** 区域顶部嵌入文件夹工具栏，支持跨角色/群组创建文件夹（如：`主线剧情`、`IF线`、`日常` 等）并将任意最近对话归类收纳。
   - 每条最近对话右侧操作栏新增文件夹按钮，支持点击选择、快速新建并移入、拖拽移入以及批量整理；兼容酒馆原生展开/收起更多最近对话功能，点进文件夹即可查看其中全部对话。
   - 同时在「管理对话文件」弹窗（`Manage chat files`）及右下角扩展菜单（魔杖图标 -> **将当前对话放入文件夹**）提供分类整理入口。
   - 自动同步酒馆内的对话重命名、对话删除、角色重命名与角色删除事件。

3. **设置与数据备份**
   - 在 **扩展（Extensions）→ 文件夹管理** 面板中可配置：
     - 根目录是否隐藏已归类的角色卡 / 对话
     - 界面语言（自动跟随酒馆 / 简体中文 / English）
     - 一键导出 / 导入文件夹配置 JSON 备份
     - 清理已删除角色残留记录

## 安装方式

### 方法一：本地手动安装（推荐）
将本插件目录（包含 `manifest.json`、`index.js`、`style.css`、`src/` 等文件）整体复制到一个文件夹（例如命名为 `SillyTavern-Folders`），放入酒馆的扩展目录之一：

- **当前用户扩展目录（推荐）**：`SillyTavern/data/default-user/extensions/SillyTavern-Folders/`
  > 如果你启用了多用户模式，请将 `default-user` 替换为你的用户名。
- **或全局第三方扩展目录**：`SillyTavern/public/scripts/extensions/third-party/SillyTavern-Folders/`

复制完成后，刷新 SillyTavern 网页即可生效（可在「扩展」面板确认已启用 `Folders (角色与对话文件夹)`）。

### 方法二：通过 Git 仓库安装（推荐）
在 SillyTavern 的 **扩展（Extensions）→ 安装扩展（Install extension）** 中直接填入本仓库地址即可一键安装与更新：

```text
https://github.com/sanfangx/sillywenjianjia
```
